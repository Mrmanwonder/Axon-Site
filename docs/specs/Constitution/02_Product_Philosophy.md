# AXON Production Constitution

# Chapter 2 — Product Philosophy

## 1. Evidence over confidence

The system must not turn model fluency into product certainty. Marks, question
boundaries, teacher annotations, extracted answers, and explanations must remain
traceable to source evidence.

## 2. Honest uncertainty

If evidence is incomplete or contradictory, the product should ask for review,
show uncertainty, or withhold the claim. A plausible wrong answer is worse than
an explicit gap.

## 3. Student correction is part of the system

Review is not an error screen. Student confirmation/correction is an intended
stage in the pipeline and should improve the trustworthiness of downstream
insights.

## 4. Private by default

Student papers, handwriting, answers, teacher comments, identifiers, and signed
asset URLs must not be sent to unrelated third-party tools. Web grounding must
use server-approved public academic context only.

## 5. One product loop

Axon's primary loop is:

Scan → Process → Review → Understand → Learn from confirmed history.

Do not reintroduce planner, mission, digital-twin, or generic-chat architecture
without a new explicit product decision.
