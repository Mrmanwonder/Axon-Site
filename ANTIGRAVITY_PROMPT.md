
# Antigravity Prompt

Build a premium desktop-first experience called AXON.

Do NOT build a generic SaaS dashboard.

The experience should feel like entering a quiet observatory or library rather than opening software.

Design language:
- Editorial layouts
- Apple craftsmanship
- Arc Browser elegance
- Muji restraint
- Minimal monochrome palette
- Soft ambient lighting
- Almost no saturated colors
- Rich spacing
- Cinematic transitions
- Zero AI clichés

The homepage should revolve around ONE central object:
Today's Mission.

Everything else should remain peripheral.

Avoid dashboard clutter.

Microinteractions should feel physical and intentional.

Use React + Next.js + Tailwind + Framer Motion.
Design every component from first principles instead of copying existing dashboards.

Leave placeholders for cinematic landscape artwork supplied later.
